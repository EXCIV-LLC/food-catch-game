# food-catch-game

最初のブラウザゲームです。

## 遊び方

- `index.html` をブラウザで開きます。
- `START` ボタンでゲームを開始します。
- 左右キー、またはマウス/タッチ操作でカゴを動かします。
- 落ちてくる食べ物をキャッチするとスコアが増えます。
- 時間が経つほど、食べ物が落ちる速度が速くなり、同時に落ちる数も増えます。
- 画面上の食べ物は最大4個までで、キャッチまたはミスで消えると次の食べ物が補充されます。
- 食べ物を取り逃してLifeが0になるとゲームオーバーです。
- ゲームオーバー後はリトライ、またはタイトル画面へ戻ることができます。

## ベストスコア保存

ベストスコアはブラウザの `localStorage` に保存されます。

- 保存キー: `foodCatchGameBestScore`
- 現在スコアがベストスコアを超えた時点で自動保存します。
- ページを閉じても、同じブラウザで開くとベストスコアが復元されます。

## 画像アセット

食べ物とカゴは `assets/` フォルダ内の画像をCanvasに描画しています。

## スマホ対応

スマホ幅ではゲーム画面をブラウザの表示領域いっぱいに広げ、スコア表示が見切れないように上部UIをコンパクトにしています。

## 効果音

キャッチ時とミス時にWeb Audio APIで短い効果音を鳴らします。

## タイトル画面

タイトル画面にはロゴ、Bestスコア、カゴのキャラクターを表示しています。

## 広告枠

タイトル画面とゲームオーバー画面にダミーの広告枠を表示しています。プレイ中は表示しません。
