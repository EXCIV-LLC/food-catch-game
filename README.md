# food-catch-game

最初のブラウザゲームです。

## 遊び方

- `index.html` をブラウザで開きます。
- `START` ボタンでゲームを開始します。
- 左右キー、またはマウス/タッチ操作でカゴを動かします。
- 落ちてくる食べ物をキャッチするとスコアが増えます。
- 時間が経つほど、食べ物が落ちる速度が速くなります。
- 食べ物を取り逃してLifeが0になるとゲームオーバーです。

## ベストスコア保存

ベストスコアはブラウザの `localStorage` に保存されます。

- 保存キー: `foodCatchGameBestScore`
- 現在スコアがベストスコアを超えた時点で自動保存します。
- ページを閉じても、同じブラウザで開くとベストスコアが復元されます。
