# food-catch-game

HTML5 Canvasで作成したブラウザ向けミニゲームです。

## Playルール

タイトル画面から `START` を押すと、ルール確認と難易度選択に進みます。

- 操作は左右キー、またはマウス/タッチ移動です。
- カゴを動かして、落ちてくるアイテムを受け止めます。
- 通常フードをキャッチすると `+10` 点です。
- 通常フードを取り逃すとLifeが1減ります。
- ゴールドフードをキャッチすると `+35` 点です。
- 連続キャッチでコンボが増え、5コンボごとに追加点が入ります。
- ハートをキャッチするとLifeが1回復します。取り逃してもペナルティはありません。
- ボムに当たるとLifeが1減り、コンボがリセットされます。避ければペナルティはありません。
- Lifeが0になるとゲームオーバーです。
- ゲームオーバー後はスコア、ベストスコア、難易度、最大コンボを確認できます。
- 画面上部の `Speed Lv` ゲージは、落下速度レベルの上昇具合です。時間経過で上限なくレベルが上がり、落下速度も上がり続けます。

## 難易度

- やさしい: 落下アイテム最大2個、落下速度は遅め
- ふつう: 落下アイテム最大3個、標準速度
- むずかしい: 落下アイテム最大4個、以前の速度設定

時間経過で落下速度が上がり続け、画面上の同時落下数も難易度ごとの最大数まで増えていきます。
落下速度は現在の `Speed Lv` として画面上部に表示されます。

## 追加した主な機能

- タイトル画面のデザイン調整
- ルール説明付きの難易度選択画面
- スコア、ベスト、Life、コンボ、経過時間を表示するHUD
- ゴールドフード、ハート、ボムの追加
- コンボボーナスと最大コンボ表示
- 背景、浮きスコア、簡易グローなどの演出
- スマホ画面向けのレスポンシブUI
- ダミー広告枠

## ベストスコア保存

ベストスコアはブラウザの `localStorage` に保存されます。

- 保存キー: `foodCatchGameBestScore`
- 現在スコアがベストスコアを超えた時点で自動保存します。
- ページを閉じても、同じブラウザで開くとベストスコアが復元されます。

## ファイル構成

- `index.html`: 画面の基本構造
- `style.css`: レイアウト、HUD、タイトル/リザルト画面の見た目
- `game.js`: ゲームロジック、描画、入力、スコア保存
- `assets/`: 食べ物、カゴ、ロゴ、マスコット、ボム、ゴールドフードなどの画像

## キャッシュ対策
